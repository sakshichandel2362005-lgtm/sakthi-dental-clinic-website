# Sakthi Dental Clinic Website

## Project Overview
Sakthi Dental Clinic is a responsive website designed to provide information about the clinic, its dental treatments, facilities, and contact details.

## Features
- Home page with clinic introduction
- About Us page
- Dental treatments listing
- Facilities and testimonials sections
- Contact form with demo validation
- Privacy Policy page
- Responsive layout for mobile and desktop
- Navigation menu between pages

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Pages
- `index.html` — Home page
- `about.html` — About Us
- `treatments.html` — Dental treatments
- `privacy.html` — Privacy Policy

## Important Note
The contact form is for demonstration purposes only. It does not send appointment requests to the clinic.

## How to Run
1. Open the project folder in Visual Studio Code.
2. Open `index.html` using Live Server.
3. Explore the website through the navigation menu.
